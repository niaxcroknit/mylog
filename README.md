# 출시 안내 (처음부터 끝까지)

## 1부. 안드로이드 스튜디오

### 1. 이 저장소로 프로젝트 열기
압축 파일로 열어 둔 프로젝트와 내용이 같아요. 앞으로 고친 내용을 깃허브와 맞추려면 이 저장소에서 다시 여는 게 좋아요.

1. 안드로이드 스튜디오 → **File → New → Project from Version Control…**
2. URL에 `https://github.com/niaxcroknit/mylog.git` → 저장할 폴더 고르기 → **Clone**
3. "Trust Project?" → **Trust Project**. 아래 Gradle 진행 막대가 끝날 때까지 기다려요.
4. 이런 안내가 뜨면
   - "Android SDK Platform 36 is not installed" → **Install missing platform**
   - "Android Gradle Plugin 업그레이드" → **Upgrade**
   - 빨간 오류 → 오류 문장을 그대로 복사해서 Claude에게 보여 주세요.

### 2. 휴대폰에서 실행해 보기
1. 휴대폰 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호 7번** 누르기 → 개발자 옵션 → **USB 디버깅** 켜기
2. USB로 연결하고 허용 → 위쪽 기기 목록에서 내 폰 선택 → 초록색 ▶
3. 확인할 것
   - 기록 적기, 눌러서 완료(×), 좌우로 밀어 날짜 넘기기
   - 뒤로 가기: 열린 창 닫힘 → 첫 페이지 → 앱 닫힘
   - ⚙ → 백업 파일 저장 → 백업 불러오기
   - 다크 모드, 화면 돌리기

### 3. 스토어에 올릴 파일(.aab) 만들기
1. **Build → Generate Signed App Bundle or APK…** → **Android App Bundle** → Next
2. Key store path 옆 **Create new…**
   - 저장 위치: 프로젝트 폴더 **바깥** (예: 문서 폴더 `mylog-upload-key.jks`)
   - 비밀번호 두 개, Alias(`upload`), 이름 → OK
3. **release** → Create
4. 결과: `app/release/app-release.aab`

> ⚠️ 키 파일(.jks)과 비밀번호는 클라우드와 USB 두 곳 이상에 보관하세요. 업데이트마다 같은 키가 필요해요. 키 파일은 이 저장소에 올라가지 않게 막아 뒀어요.

## 2부. 구글 플레이 콘솔

### 1. 앱 만들기
**모든 앱 → 앱 만들기**
- 앱 이름: `마이로그 - 도트 불렛저널 다이어리`
- 기본 언어: 한국어 / 앱 / 무료 → 정책 동의 → **앱 만들기**

### 2. 앱 설정 (대시보드 할 일)

| 항목 | 답 |
|---|---|
| 개인정보처리방침 | `https://app.notion.com/p/4054235ad3ee80cf9ec0df8bc6ff88cf` |
| 앱 액세스 권한 | 모든 기능을 별도 제한 없이 사용 가능 |
| 광고 | 광고 없음 |
| 콘텐츠 등급 | 카테고리 **기타(유틸리티, 생산성 등)** → 질문 모두 **아니요** |
| 타겟층 | 만 18세 이상 |
| 뉴스 앱 | 아니요 |
| 데이터 보안 | 사용자 데이터를 수집하거나 공유하지 않음 |
| 정부 앱 / 금융 기능 / 건강 앱 | 해당 없음 |

> 노션 링크는 **로그인하지 않은 시크릿 창**에서도 열리는지 꼭 확인하세요. 노션 페이지 오른쪽 위 **공유 → 게시 → 웹에 게시**가 켜져 있어야 해요.

### 3. 스토어 등록정보
**성장 → 스토어 등록정보 → 기본 스토어 등록정보** (`store/` 폴더)
- 이름, 간단한 설명, 자세한 설명: `store/listing.txt`에서 복사
- 앱 아이콘: `store/images/icon-512.png`
- 그래픽 이미지: `store/images/feature-1024x500.png`
- 휴대전화 스크린샷: `phone-1` ~ `phone-6`
- 7인치·10인치 태블릿 스크린샷: `tablet-1` ~ `tablet-3` (두 칸 모두)
- 스토어 설정: 카테고리 **생산성**, 이메일 `kimseohappiness@gmail.com`

### 4. 비공개 테스트 (14일)
1. **테스트 및 출시 → 테스트 → 비공개 테스트** → 트랙(Alpha) → 국가: 대한민국
2. **테스터** → 이메일 목록 만들기 → 지메일 12개 이상
3. **새 버전 만들기** → Play 앱 서명 **사용** → `app-release.aab` 업로드 → 출시 노트(`store/listing.txt`의 "이번 버전의 새로운 기능") → 검토 → **출시 시작**
4. 검토가 끝나면 **참여 링크**를 테스터에게 보내요. 테스터는 "테스터 되기" → 설치 → **14일 동안 지우지 않기**

### 5. 정식 출시
1. 14일 뒤 대시보드 **프로덕션 액세스 신청** → 테스트 경험 질문에 짧게 답하기
   - 예: "지인 12명이 14일 동안 데일리 기록, 만년다이어리, 습관, 백업 기능을 써 보고 의견을 줬고, 버튼 글자 줄바꿈과 입력칸 글꼴 문제를 고쳤습니다."
2. 승인 후 **프로덕션 → 새 버전 만들기 → 라이브러리에서 추가** → 출시

## 3부. 업데이트할 때
1. 웹 화면은 `docs/index.html`을 고치고 `python3 tools/build_app_page.py`로 앱 화면에 반영해요.
2. `app/build.gradle.kts`에서 `versionCode` +1, `versionName` 변경 (예: 2 / 1.0.1)
3. 같은 키(.jks)로 .aab를 만들어 콘솔에 올려요.
